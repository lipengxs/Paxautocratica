# Colony Fieldnotes

Independent, unofficial reading resource about PAX AUTOCRATICA. Not affiliated with the game’s developers or publishers.

Static HTML/CSS hosted through the existing Cloudflare Pages integration. No build step or npm dependencies are required. Publish the repository root. `_worker.js` routes requests and applies security headers; `_routes.json` includes all paths. The public routes are `/`, `/guides`, `/media`, `/news`, `/privacy-policy` and `/terms-of-service`.

The current site has no advertising, analytics, remote embeds, game accounts, payment processing or game downloads. Media pages link to original sources. `sw.js` and the local maintenance script retire former browser workers and cached files; do not remove the retirement endpoint without considering previous visitors.
