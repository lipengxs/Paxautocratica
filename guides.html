Before you play

  1. Check the current game description.

    Read the official website ↗ for the developers’ description of the game. Features and availability can change.

  2. Check requirements and availability.

    Open the Steam listing ↗ and review its current system requirements, supported languages, availability and purchase information before making a decision.

  3. Use official help for game issues.

    Use the support links on the official game website ↗. Do not send game passwords, verification codes, payment details or save files to this independent site.
